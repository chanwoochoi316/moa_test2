근거: 2026-11-06 SSRD/SSAD/UI·UX 기획안. 여기서 '구현'은 **소스코드에 기능이 있다는 뜻**이며, Vercel/Supabase 실제 서비스에 대한 통합 테스트 완료를 의미하지 않습니다.

## 안전·운영 필수 점검

- 개발자 테스트를 위한 가짜 결제입니다. **실제 1,000원 청구 없음**. 실제 유료로 출시하려면 PG, 약관, 환불 정책, 관련 규제 검토가 별도로 필요합니다.
- 특정 종목·상품 추천/수익률 보장/투자 실행 불가. 위험 성향에 따른 자산 **종류** 가이드를 제시하는 교육용 프로토타입입니다.
- 원본 SSAD의 개인정보·보안 요구사항을 소스 일부에 반영했지만, 온라인 공개 전 **두 계정 간 접근 차단·탈퇴 데이터 삭제·실제 Supabase RLS·이메일 인증**을 반드시 직접 검증해야 합니다.
- API 비용과 포인트는 서로 다릅니다. Anthropic 실제 과금 상한을 기술적으로 보장하는 서버 전체 제한은 없습니다. 테스트 중에는 `AI_ENABLED=false`를 권장합니다.
- 본 기능표는 2026-11-06 문서 기준, 이전 MOA 목표저축앱과 다른 신버전입니다.
